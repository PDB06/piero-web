# Cómo cambiar la web (para Piero)

La web se edita hablándole a Claude. No hace falta tocar código.

## La primera vez
1. Aceptá la invitación de GitHub al repo `piero-web` (te llega por mail).
2. Entrá a **claude.ai/code** (o la app de Claude → Code) y conectá tu GitHub.
3. Cuando te pida darle acceso a repos, elegí `franaltt/piero-web`.

## Cada vez que quieras cambiar algo
1. Abrí una sesión nueva de Claude Code en el repo `piero-web`.
2. Pedile lo que quieras, normal, como a una persona:
   - "Subí el precio del plan Estándar a 490"
   - "Activá una oferta de Black Friday: el piloto a 150 hasta el 30 de noviembre"
   - "Agregá este video al carrusel de trabajos" (y le pasás el archivo)
   - "Cambiá el texto de arriba por: …"
   - "Sumá una guía nueva en Recursos con esta portada"
3. Claude hace el cambio y te pasa un **link de vista previa**. Abrilo en el celular y en la compu.
4. Si está bien, decile **"publicalo"**. En 1-2 minutos está en la web real.
5. Si no te gusta, decile qué cambiar, o "descartalo" y no pasa nada: la web publicada no se toca hasta que digas publicalo.

## Tips
- Un pedido por sesión sale mejor que diez juntos.
- Si querés algo grande (una sección nueva, cambiar el estilo), contáselo con detalle o pasale una referencia.
- La web está en español, italiano e inglés: Claude actualiza los tres idiomas solo.
